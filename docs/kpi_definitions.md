# KPI Definitions

- **Gross Fees** = SUM(charged_fee)
- **Expected Fees** = SUM(expected_fee)
- **Fee Leakage** = SUM(MAX(expected_fee - charged_fee, 0))
- **Leakage %** = Fee Leakage / Expected Fees
- **Reconciliation Rate** = reconciled transactions / total transactions
- **Exception Count** = non-reconciled transactions
- **Average Fee / Transaction** = Gross Fees / transaction count
- **MoM Revenue Change** = current-month Gross Fees vs previous month
