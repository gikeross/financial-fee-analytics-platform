# Dashboard Specification

## Executive Overview
KPIs: Gross Fees, Expected Fees, Fee Leakage, Leakage %, Reconciliation Rate, Exception Count.

Visuals: monthly charged vs expected fees, leakage by product, reconciliation trend, gross fees by country.

## Product Performance
KPIs: Transaction Value, Gross Fees, Average Fee / Transaction, Fee Leakage, Reconciliation Rate.

Visuals: product revenue, transaction value vs fee revenue, product/channel leakage, client-segment contribution.

## Fee Exceptions
KPIs: Exception Count, High-Risk Exceptions, Revenue at Risk, Average Leakage / Exception, Exception Rate.

Visuals: leakage by priority, exceptions by product, monthly trend, transaction-level investigation table.
